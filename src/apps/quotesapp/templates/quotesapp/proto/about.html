About

A commonplace book: passages I saved while reading books, papers and web pages, each kept with its source and a few tags.

The background is in this blog post. The quotes are plain markdown files; the site is a small Django app mirrored to static HTML with wget, as described in A static site generator using Django, Wget and Github Pages.

Browse by tag or by source, or go back to michelepasin.org.
