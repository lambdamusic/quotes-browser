Brain Rules for Baby (John Medina) / quote 44 of 91

Emotional regulation predicts cognitive performance

These data flatly state that emotional regulation—reining in impulses—predicts better cognitive performance. That’s a bombshell of an idea. It directly ties intellectual horsepower to emotional processing. I am not dismissing rote drills, as a memorized database is an extremely important part of human learning. But it is clear: Vygotsky was on to something.
