Adesso basta (Simone Perotti) / quote 101 of 106

La tecnologia non estingue le relazioni

Hai voglia a dire che il telefono avrebbe estinto le relazioni personali. Non è andata così, come tuonavano i soliti catastrofisti retrogradi. È stata detta la stessa cosa per la posta elettronica. L’uomo tende a frequentarsi, ad onta di qualunque remotizzazione della comunicazione.

Saved 28 November 2014 / www.amazon.com ↗
