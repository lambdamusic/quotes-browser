Staying the same through steady change

We can remain the ‘same’ through great change because it is of the nature of persons that they change, and so our continued existence as the same person requires only that there is a steady enough process of change, not that we remain identical in any particular respect. It is because we are not pearls that we transform over time and can still be thought of as the same person over time.
